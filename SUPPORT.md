# Support

Beam Research Toolkit is a commercial desktop app. This public repository is for **documentation and issues**, not source contributions.

## Product problems

Use [GitHub Issues](../../issues) with the right template:

- **Bug** — crashes, wrong plots, failed exports, install/launch problems
- **Feature** — a workflow you cannot complete in v1.0
- **Question** — first-run confusion, “is this for students?”, GEANT4-in-Beam orientation

We read these. A short reproduction beats a long theory.

## Account, trial, billing

Do not put emails, Stripe receipts, or license keys in a public issue.

Write [support@qirexscientific.com](mailto:support@qirexscientific.com).

Trial: 14 days full access after you launch the app.  
Then €24 / month or €240 / year, subscribed **inside the app**.

Website account page (status + billing portal only): https://qirexscientific.com/account.html

## Security

See [SECURITY.md](SECURITY.md). Do not file security reports as public issues.

## Pull requests

There is no application source here. PRs that add docs, screenshot captions, or issue-template fixes are welcome. PRs that expect a compile tree will be closed with a pointer to this file.
