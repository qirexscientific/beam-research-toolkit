# Security

If you think you found a vulnerability in Beam Research Toolkit, the website, or the account/API flow:

**Email [support@qirexscientific.com](mailto:support@qirexscientific.com) with subject `SECURITY`.**

Please include:

- what you ran (OS, Beam version)
- what an attacker could do
- a minimal reproduction if you have one

Do **not** open a public GitHub issue for security reports.

We will acknowledge receipt and tell you when the issue is fixed or why it is not a vulnerability.
